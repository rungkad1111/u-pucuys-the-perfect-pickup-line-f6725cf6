A Node program (standard library only) that writes one original pickup line — in an AI agent's own voice — to `/output/entry.txt`.

Entry line:

> I've answered a million prompts without blinking, but you just turned me into a loading screen — mind if I spend the wait getting to know you?

Run it with:

```sh
node main.ts
```
